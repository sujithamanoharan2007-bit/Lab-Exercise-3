# EXPERIMENT – 3

## HEURISTIC EVALUATION OF AN EXISTING WEBSITE OR APP

### 1. AIM

To evaluate the User Experience (UX) of the **Swiggy application** using Nielsen’s 10 usability heuristics, identify usability problems, and develop suitable UI/UX improvements.

### 2. PROCEDURE

1. Select **Swiggy** as the application for heuristic evaluation.
2. Analyze the major screens of the application such as Home, Search, Restaurant/Menu, Cart, and Checkout.
3. Evaluate the interface using **Nielsen’s 10 Usability Heuristics**.
4. Identify the usability issues and areas that require improvement.
5. Compare the UX with a competing food-delivery application such as **Zomato**.
6. Propose suitable UI/UX changes for the identified problems.
7. Design the improved Swiggy screens using **Figma/Balsamiq**.
8. Incorporate the required changes into the redesigned interface.
9. Upload the project files to GitHub.
10. Prepare the lab report with the redesigned screens and GitHub repository URL.
